# Codex 额度

Windows 本地插件，将本机当前登录账号的 5 小时／每周剩余额度显示在 Codex 内容侧栏。

## 打开

在聊天右上角的内容页“＋”菜单选择 **Codex 额度**，可在当前聊天旁边打开面板。也可以在聊天中说“打开额度面板”。左侧导航的 **额度看板** 是独立的全屏入口。

每个聊天拥有独立的面板实例。官方扩展提供的是内容侧栏入口，首次使用时需要打开该入口，不会改写 Codex 自身的聊天布局。

如果首次安装后没有出现入口，重启 Codex，再打开同一聊天查看。

## 刷新与数据

- 面板可见时每 5 分钟自动更新，点击“立即刷新”可以立即读取；隐藏后恢复可见时，会补做已到期的刷新。
- 显示剩余百分比、重置时间、套餐、来源和记录时间。手动刷新不会改变旧快照的原始时间。
- 优先使用官方账户额度接口；不可用时，显示带原始时间的本机记录。过了重置时间的旧记录显示“待更新”。
- 查询额度不发起模型对话。界面只与本机插件通信，不需要额外 API Key，不读取、保存或上传登录凭证内容。

## 运行环境

Windows 10/11、已登录的 Codex、Node.js 22 或更高版本，以及 .NET Framework 4.8。`bin/QuotaReader.exe` 是此前验证过的本地查询程序，只以 `--check` 模式运行。

源码、安装说明及效果截图见 [GitHub 仓库](https://github.com/voniat/codex-quota-panel)。安装后由 Codex 使用自己的插件缓存副本。

在插件设置中可停用或卸载 **Codex 额度**。查询组件已独立包含在插件中，运行和重新构建均不依赖此前的桌面悬浮窗。

此为个人本地扩展，不是 OpenAI 官方额度产品。
