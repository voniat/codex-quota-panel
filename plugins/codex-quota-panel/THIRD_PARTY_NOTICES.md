# Bundled libraries

The server and UI bundle official MCP libraries and their dependencies. Original license comments are retained by the bundler.

- `@modelcontextprotocol/sdk` 1.32.2 — MIT — https://github.com/modelcontextprotocol/typescript-sdk
- `@modelcontextprotocol/ext-apps` 1.7.5 — Apache-2.0 — https://github.com/modelcontextprotocol/ext-apps
- `zod` 4.6.7 — MIT — https://github.com/colinhacks/zod

The build uses `esbuild` 0.28.2 (MIT); it is not needed to run the packaged plugin.
